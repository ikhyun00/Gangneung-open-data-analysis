## 📖 프로젝트 개요

강릉시는 인구 천 명당 주차면 수가 668면으로 많은 편이지만, **주차장이 생활권이 아닌 관광지에 밀집**되어 거주민의 주차 문제가 지속적으로 발생하고 있습니다.  
본 프로젝트는 공공데이터를 기반으로 **20개 행정읍면동의 주차 수요를 분석하고 최적의 주차타워 입지를 도출**하는 것을 목표로 합니다. (2024 강릉시 데이터분석 공모전)

---

## 🎯 분석 목표

- 강릉시 주차 수요 및 공급 구조 분석
- 거주민 생활권의 주차 부족 지역 도출
- 데이터 기반 최적 주차타워 입지 선정
- 정책 활용 가능한 인사이트 제공

---

## 📊 데이터 구성

공공데이터(2023 강릉시 통계연보, 공공데이터포털, 한국관광 데이터랩)를 활용하여 주요 변수를 구축했습니다.

| 변수 | 설명 |
|------|------|
| 주차장면적 | 지역별 주차 공간 규모 |
| 등록차량수 | 차량 수 |
| 관광객수 | 유동 인구 |
| 인구수 | 상주 인구 |
| 사업체수 / 종사자수 | 경제 활동 |
| 금융시설 / 문화시설 | 인프라 |
| 수요량 | 등록차량수 − 주차장수용대수 |
| 주차부족지수 | 수요량 − 주차공급량 |

---

## ⚙️ 데이터 전처리

- 문자열 숫자 데이터 정제 (쉼표 제거 후 numeric 변환)
- 변수 표준화 (Z-score)
- 결측치 처리 (결측이 많은 주차장 면수 대신 주차장 면적 사용)
- 파생 변수 생성 (차량 1대당 주차 공간 12.5㎡ 가정)

📌 주요 파생 변수
- 주차 수요지수
- 경제지수
- 인프라지수
- 수용지수

---

## 📈 분석 방법

### 1. 변수 중요도 분석
- Random Forest 기반 변수 중요도 도출  
- 중요도를 지수 가중치로 활용

### 2. 지수 생성
각 변수 중요도를 기반으로 가중치 적용

- 주차수요지수 = 관광객수 × 0.31 + 등록차량수 × 0.44 + 인구수 × 0.25
- 경제지수 = 종사자수 × 0.82 + 사업체수 × 0.18
- 인프라지수 = 금융시설 × 0.53 + 문화시설 × 0.47
- 수용지수 = 주차장수용대수 × 0.6 + 수용률 × 0.4

---

### 3. 군집 분석

- 엘보우 방법으로 군집 수 k = 3 결정
- K-means Clustering (군집 크기 3 / 2 / 15, 불균형)
- K-medoids Clustering (군집 크기 6 / 11 / 3) → **이상치에 강하고 균형 잡힌 K-medoids 채택**

👉 주차수요지수와 주차부족지수가 높은 군집에서 후보 6개 동(강남동, 내곡동, 홍제동, 포남2동, 성덕동, 교1동) 선정

---

### 4. 머신러닝 모델

- Random Forest 활용
- 주차부족지수를 종속변수로 변수 중요도(%IncMSE) 분석
- 중요도 순위: 수요량 > 주차수요지수 > 수용지수 > 경제지수 > 인프라지수

---

### 5. 최적 입지 선정

다중 지표를 결합한 최종 평가식:

Z = 0.35 × 수요량  
  + 0.30 × 주차수요지수  
  + 0.19 × 수용지수  
  + 0.14 × 경제지수  
  + 0.02 × 인프라지수  

---

## 📌 주요 분석 결과

- 관광객 수 상위 지역은 인구 대비 주차 면적이 넓고, 하위 지역은 매우 좁음 → **주차장이 관광지에 편중**
- 후보 6개 동의 Z 점수: 교1동 1.75 > 성덕동 1.12 > 홍제동 0.23 > 강남동 0.16 > 포남2동 0.14 > 내곡동 0.09
- 최적 입지:

👉 교1동, 성덕동
